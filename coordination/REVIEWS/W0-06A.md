## Findings requiring a bounded correction

1. **Required real-Mongo audit chain fails under concurrency.** `backend/app/files/registry.py:204` appends via `app.audit.store.record_event()`. That store reads the last event and inserts the next sequence without atomic serialization; simultaneous registry writes for the same tenant read the same predecessor. The committed real-Mongo test reproduces duplicate sequence `[1, 1, 2, 3]` twice. The File Registry's audit guarantee is therefore unproven and the 0-failed gate is not met. Correct the write/chain behavior or the registry integration in a bounded, tenant-safe way and rerun the committed test independently; do not weaken or skip it.
2. **Relation target verification is caller-bypassable.** The public `register_file(... verify_relation_targets=False)` and `add_relation(... verify_target=False)` paths in `backend/app/files/registry.py` skip `_assert_relation_target()` but still persist a tenant-tagged FileRelation to any `record_id`. An unverified/foreign-only target can thus be linked despite the assignment's fail-closed relation boundary. Remove the bypass from public writes or constrain it behind a separately proven migration-only mechanism; add a negative regression.
3. **Version-specific delete result overstates destruction.** `request_physical_delete()` accepts `version_no`, yet `record_delete_result()` updates *all* provider locations for the `file_id` to `MISSING` and marks the whole file `deleted_at_provider` when any request is confirmed (`backend/app/files/registry.py:868, 944`). A receipt for version 1 can make version 2 appear destroyed without provider evidence. Scope the result to the requested version/object and preserve unrelated versions, or explicitly refuse version-specific requests until safe; test multi-version behavior. No real delete was attempted.
4. **Checksum test nondeterminism.** Make the committed duplicate-checksum acceptance test deterministic under equal timestamps, and confirm the product's candidate-selection contract. The current full focused run is 160/161, not PASS.
