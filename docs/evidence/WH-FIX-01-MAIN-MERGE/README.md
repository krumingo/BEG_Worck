row (FG-159, package WH-FIX-01; FLOW-009 one writer). The SEC-01 harness body has no Master

  (`money_value` and the key check before `post_project_writeoff`, no direct write) and the

The canonical write-off's rights in 3 modes, idempotent replay, value and AuditEvent are proven

## WHFIX81-01 lock moved onto the supplier invoice document

The SEC-01 two-tenant probe attributes every written row to a tenant; the first write of the
WHFIX81-01 lock CREATED the `warehouse_ledger_counters` collection (a command with no tenant).
The lock is now the supplier invoice document itself (`link_lock_seq` `$inc`, written by the
PUT and by every linking receipt in their transactions) — same serialization, no new
collection, always the tenant's own row.
