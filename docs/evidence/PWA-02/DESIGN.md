## Нови колекции (ORG_KEYED, регистрирани в `ownership.py`)
| колекция | ключ | предназначение |
|---|---|---|
| `sync_devices` | org_id+device_id | регистър, last_sync_at, revoked_at/by/reason |
| `sync_receipts` | org_id+user_id+idempotency_key (уникален) | резултат на всеки изпратен запис; ≥30 дни |
| `sync_conflicts` | org_id+id | теренна/офисна версия, diff, автор, час, решение |
| `sync_late` | org_id+id | закъснели записи, чакащи офиса |
| `sync_quarantine` | org_id+id | записи от блокирано устройство |

Индексите се създават с `ensure_sync_indexes_for_installation` (същия модел като `overhead_lifecycle`). В main няма migration runner (дълг).

## `base_version`
В main няма поле за версия. Предложение: `base_version` = `updated_at` на записа (непрозрачен низ), който телефонът е видял. Ако е различно → конфликт. Не се добавя ново поле към съществуващите колекции.
