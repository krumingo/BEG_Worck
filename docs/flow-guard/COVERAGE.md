# FLOW GUARD — покритие на main по FLOW

Бавен преглед: по един FLOW на проход. Легенда:

- ✅ — изпълнено;
- ⚠️ — частично;
- ❌ — противоречи на канона;
- ⏳ — още не е изпълнено (не е разминаване, ако вълната не е стигнала дотам).
