## Проблем (main, `backend/app/routes/overhead.py`)

## Какво да се направи
1. DELETE на категория/разход/актив: ако записът е използван (в разпределение, snapshot, разход) → 409; ако не е използван → архивиране (`status=archived`, кой/кога/причина), не изтриване. Списъците по подразбиране скриват архивираните.
2. Повторно разпределение: нова версия на snapshot-а/разпределенията; предишната остава със `superseded_by` и не участва в справките; P&L/отчетите четат само активната версия.
3. AuditEvent за архивиране и за нова версия; Idempotency-Key по Р29 за тези money записи; права — само финансови роли (както SEC-01, #69 — ако `require_money_write` още не е в main, ползвай текущата проверка и опиши в HANDOFF сливането с #69).
4. Без миграция на стари данни (липсващ status = активен).
