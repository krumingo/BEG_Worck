# LAB-01 — трудът се смята по FLOW-019/028 (заплата и акорд), само от одобрени отчети
> ОДОБРЕНА — прилагане на заключен канон: FLOW-019 (реален трудов разход само от одобрени дневни отчети; престой — отделен ред DOWNTIME), FLOW-028 (заплата / акорд / Pay Run), CLAUDE.md §7 („Акордът изисква одобрено количество × единична цена труд“), FLOW-043 D-02, Р31 (Крум, 06.11.2026: „Има FLOW за това“). Нов PR от `main`. Codex: да (пари — заплати).

## Проблеми (FLOW Guard pass 4, SEC-02-C-D1)
- **FG-48 (HIGH, PROVEN):** Pay Run плаща акорд като часове × ставка — `calc_earned` (`routes/pay_runs.py:185`) не получава одобрената стойност; pay_type Акорд, 40 ч @ 15 → 600, формулата пише „(акорд)“.
- **FG-51 (HIGH, SUSPECTED):** `sync-from-work-reports` чете отчети без филтър Approved и винаги часове × ставка.
- **FG-49 (medium, SUSPECTED):** типът заплащане се взима само от профила, не от реда по СМР.
- **SEC-02-C-D1:** „изхарчено“ (expected_actual и сродни) ползва work_sessions/чернови, ставка по подразбиране 25, няма отделен престой.

## Какво да се направи
1. Една обща функция (един източник) за трудов разход по ред от отчет: заплата → одобрени часове × ставка; акорд → **одобрено** количество × акордна цена (от реда/договора по СМР; ако липсва — ред с DQ предупреждение и 0, не измислена стойност). Типът заплащане — от реда/СМР, с резерв профила; опиши приоритета.
2. Pay Run, labor sync, „изхарчено“ по СМР (R31), P&L/отчетите за труд — всички през нея. Само одобрени отчети. Без ставка по подразбиране 25 — липсваща ставка = DQ предупреждение.
3. Престой — отделен ред/тип DOWNTIME в изхарченото, не в основното СМР.
4. Съществуващи Pay Run-ове **не се преизчисляват мълчаливо**: вече изплатени/одобрени остават; разлика → отчет (correction/reversal път по CLAUDE §7), не редакция. Опиши в HANDOFF какво става с отворени (неодобрени) Pay Run-ове.
5. Правата/видимостта по R20/R31 остават (SiteManager — само сума по СМР).
## Тестове (real Mongo)
- акорд 40 ч, 120 м2 одобрени × 5 → 600 по количество (не по часове); неодобрено количество → не влиза; липсва акордна цена → DQ + 0.
- заплата: само одобрени часове; чернова → не влиза; без ставка → DQ, не 25.
- престой отделно; сума по СМР = сума на редовете; Pay Run и „изхарчено“ дават едно число за един човек/период.
- R0/W0 baseline, A2C/A1 0.
