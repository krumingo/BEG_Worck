## Правило за прилагане
1. **Финанси на ниво фирма** (каса, режийни, бонуси, P&L на фирмата, cashflow, заплати/pay-runs, оборот, фирмени отчети, overhead, fixed expenses, contract-payments, employee cost): само Owner/Admin/Accountant.
2. **Пари на ниво обект** (себестойност, марж, печалба, фактурни редове, pricing/price modifiers, revenue/expense, P&L на обекта, net profit, risk/alerts с пари): Owner/Admin/Accountant навсякъде; **проектни ръководни роли** (SiteManager) — само на свои обекти, ако съседните екрани в същия модул вече им го дават (цитира се файл:ред); **Viewer, Technician, Driver, Warehousekeeper — не**.
3. **Не-финансови данни на обекта** (ход, задачи, отчети, снимки, количества без стойности): по членство, както досега.
4. Склад: количества да, стойности/себестойност не — за роли без финансово право.
5. Отказ → 403 (или полето скрито, ако екранът е общ и правилото в модула е „скрий стойностите“ — описва се). Frontend: менюта и бутони по права, без празни екрани с 0.
